# legacy（归档目录）

> 当前正式版为 neca v0.3.0；本目录不随版本发布，只用于回退与影子测试。

这里保存 neca 的上一代 bash 实现，**只读归档，不再维护**：

| 文件 | 说明 |
|---|---|
| `vpn-cert-manager.sh` | 506 行旧脚本，neca 的行为基准；M2 影子测试用它做对照 |
| [vpn-cert-manager.md](../docs/legacy-vpn-cert-manager.md) | 旧脚本的使用与二次开发说明 |

**为什么不删除**：

1. 迁移期的验收标准是"新旧输出 diff 为 0"（文档 §13.3），需要旧实现作为对照；
2. 回退时可以直接恢复旧脚本，不必从 git 历史里翻找；
3. v1.0 稳定后再评估是否移出仓库（文档 §18 待定事项）。

注意：旧脚本从仓库根目录移到这里后，文档中指向它的相对链接已同步更新；
使用时请把路径替换为 `legacy/vpn-cert-manager.sh`。
